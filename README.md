# Bridal Booking System

A web-based bridal booking and management platform developed to simplify wedding service reservations and customer communication.

## Features

- Browse available bridal and wedding packages
- View wedding photos and videos from previous events
- Online appointment and booking system
- Customer information and booking management
- Email notifications and appointment confirmation
- Responsive user interface for easy access

## Technologies Used

- PHP
- HTML
- CSS
- JavaScript
- MySQL

## Project Status

Currently in development.

## Purpose of the Project

The goal of this project is to create a digital bridal service platform that improves customer experience by allowing online package selection, appointment scheduling, and communication.

## Future Improvements

- Admin dashboard
- Payment integration
- User authentication system
- Booking history tracking
- Mobile optimization
